# CLI 0.5.0 与类型包同步发行准备

状态：已执行（本地准备）；治理：不可变变更记录。影响范围：CLI 与开发类型包版本、示例依赖、首次稳定发行准备。前置：[0036](0036-workflow-entrypoints.md)、[0037](0037-i18n-reference-check-and-react-templates.md)、[0042](0042-published-editor-types-package.md)。本记录不表示已上传 npm、crates.io 或完成远端 Actions；实际发行状态维护于[渠道进度](../development/channel-rollout-status.md)。

## 背景与授权

用户明确要求发布 `@kenvoy/types`，确认拥有 `@kenvoy` 组织权限，并选择“同步正式发布新 CLI 与类型包”，授权本次新版本、标签/分支推送及完整保留渠道发行，不采用 dev 预览包。

此前 CLI 与本地类型包均声明 0.4.4，但新 SDK、React 静态模板与编辑器交付并未包含在正式 0.4.4 crate。不能把 dev 声明冒充同版已发行接口，也不能重新上传源包或移动旧标签，因此 CLI 与类型包统一准备为 0.5.0。

## 方案与实施

- CLI 唯一版本源 `crates/kenvoy/Cargo.toml` 从 0.4.4 改为 0.5.0，同步根 Cargo.lock；类型包继续从实际 Cargo metadata 派生，不手工定义另一个版本。
- `git diff v0.4.4..HEAD -- crates/kengine` 无改动，KEngine 保持已发布 0.2.0，CLI 依赖约束不变，不重复上传已有引擎版本。
- 前端构建自动生成 `@kenvoy/types@0.5.0`，五例开发依赖同步指向本地内容寻址 tarball。示例继续使用 Bun，锁文件继续不提交。
- i18n-app 使用新 `useLocale()` 与函数模板，将其 `min_cli_version` 提升到 0.5.0；应用版本、项目格式 0.4.0、译文与迁移内容不变，不连接或改写示例业务库。
- create 的最低 CLI 与类型开发依赖自然派生为 0.5.0；`>=0.4.0, <0.5.0` 仍仅是项目格式区间，不能误当作 CLI 版本上限。
- CHANGELOG 以单一 `## 0.5.0` 汇总原未发布功能和发布工程变化，保留全部 0.4.4 及以下历史事实；现状文档明确区分准备状态和真实发行结果。

### 发布链前置核对

两个正式 main 入口、六个手动打包入口及现有保护规则保持：先推新标签，再快进 main；首次源包的完整树须与标签一致。九个已有远端标签均与本地保留目标一致，不重指或覆盖。GitHub main 当前未启用分支保护，现有本地 main 与 origin/main 相同，可在验证后按既有规则快进。

发布链额外检查未发现需要修复的代码缺口：空独占 CARGO_HOME 下，原样 `cargo metadata --format-version 1 --no-deps --offline --locked` 退出 0；从当时 HEAD 创建的仓库外快照、空 Cargo Home 和不存在的独占 target 下同样退出 0，且未写缓存或 target。探针源码当时仍声明 0.4.4，只证明这条 metadata 读取路径不需要缓存，不冒充 0.5.0 或 Linux runner 验收，不增加预热、联网 fallback 或重试。

正式类型资产只从同版已发布 CLI crate 下载、校验并提取，六目标 ZIP 与类型 tarball/侧车共 14 项齐全后公开 Release；npm 类型版本公开可见后才发布同版安装器，不放宽版本、来源、摘要、main、404-only 和写请求不重试边界。

### npm 首发的真实前置

注册表对 `@kenvoy/types` 实际返回 404，本机既有 npm 会话 `whoami` 实际返回 401。用户组织权限和本机可用会话是不同前置，不能据组织权限伪称已获得发布凭据。

npm 官方要求包已经存在，才能创建 Trusted Publisher。因此首次必须在正式 0.5.0 类型资产就绪后，由用户会话及账号要求的 2FA 上传精确 tarball；确认精确版本可见，再给新包独立绑定 `zerobiubiu/kenvoy`、`channels.yml`、environment 留空并允许直接 npm publish。既有 `kenvoy` 授权不修改，也不自动覆盖新包。

登录使用本任务独占临时 npm 配置，不覆盖用户现有配置，不读取或记录密码、OTP、Token；登录链接只用于当次会话，不写入长期文档。现有 omp 浏览器为隐藏模式，npm 页面停在 Cloudflare 验证，已关闭本任务标签页，未改变浏览器配置或绕过验证。

依据：[npm trust 前置](https://docs.npmjs.com/cli/v12/commands/npm-trust/#prerequisites)、[Trusted Publishing](https://docs.npmjs.com/trusted-publishers/)。手动首发、配置绑定成功和已有版本被跳过，均不等于新包真实 OIDC 上传已通过。
